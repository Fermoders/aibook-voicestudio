# AIBook VoiceStudio

Отдельное Windows-приложение для локальной озвучки русских книг. Используется
штатная библиотека OmniVoice из `debpalash/VoiceStudio`, релиз `v0.5.6`, commit
`3915a62cb482bb43117aaebab57d22745bd1cc21`. Это отдельный клиент для книг,
а не официальный интерфейс VoiceStudio. Браузер и сервер не требуются.

## Запуск

GitHub-проект: https://github.com/Fermoders/aibook-voicestudio.
Установка готовой сборки в Windows одной командой PowerShell x64:

```powershell
irm https://raw.githubusercontent.com/Fermoders/aibook-voicestudio/main/install-windows.ps1 | iex
```

Пакет включает все зависимости и модели. Visual C++ Runtime проверяется
и при необходимости устанавливается с разрешением Windows. Подробности,
выбор папки и переустановка находятся в основном README.md.

В готовой папке `dist\AIBook VoiceStudio Ready` запустите `AIBook VoiceStudio.exe`.
Python, Tk, PyTorch CUDA, FFmpeg и проверенные веса уже включены. Интернет и
установка Python не нужны. Переносите всю папку: один EXE без соседних файлов
не работает. Папка должна быть доступна для записи.

Windows 10/11 x64, рекомендуется 16 ГБ RAM. На этой машине проверяется
RTX 2070 SUPER 8 ГБ. Без NVIDIA можно выбрать CPU, но генерация медленнее.

Открываются TXT, FB2, EPUB, DOCX и PDF с текстовым слоем. Результат: WAV или
MP3. Доступны готовые постоянные голоса и клонирование своего голоса.
Настройки, черновик, история и кэш автоматически сохраняются в
`data\voicestudio`; результаты по умолчанию находятся в `outputs`.

## Редактор и плеер

- В редакторе работают Ctrl+C/X/V/A/Z/Y в русской и английской раскладке,
  Delete/Backspace для выделенного и меню по правой кнопке мыши. Вставка
  поверх выделения отменяется одним действием.
- Кнопка сохранения в режиме клонирования создаёт именованный голос без
  озвучки книги. Клонирование при запуске озвучки также сохраняет голос.
  Он появляется в общем списке с пометкой «клон»; исходная запись и ввод
  текста образца больше не нужны. Карандаш и корзина переименовывают и
  удаляют выбранный клон. Старые клоны импортируются автоматически.
- Результат загружается во встроенный потоковый плеер: пауза, остановка,
  перемотка, громкость и открытие WAV/MP3. Если аудио ещё нет, проигрывание
  запускает озвучку текста и проигрывает готовый результат.
- Выделение перед проигрыванием начинает чтение с соответствующего слова.
  После генерации слова синхронизируются с готовым звуком через локальный
  Whisper tiny на CPU в отдельном процессе. Для перехода к выделению
  нужно дождаться этой подготовки.
- «Удалять произнесённый текст» удаляет завершённые слова из черновика,
  не из исходного файла книги. Перемотка не удаляет пропущенные слова.
  Позиция, оставшийся текст и голос сохраняются при выходе; повторный
  запуск восстанавливает запись на паузе в сохранённой позиции.
- Ручная правка во время удаления приостанавливает плеер и отключает
  удаление. Ctrl+Z отменяет удаление; кнопка восстановления возвращает
  весь текст записи с подтверждением. При несовпадении редактора и
  записи синхронное удаление недоступно.
- Рядом с новым аудио сохраняется `.aibook.json` с текстом и временами слов.
  Переносите его вместе с записью для чтения по выделению. Старые записи
  без него проигрываются, но для синхронизации нужна новая озвучка.
  Позиция сохраняется и для обычных WAV/MP3 без этого файла.

Интернет для синхронизации и плеера не нужен, Whisper tiny включён в сборку.
Если Windows не предоставляет аудиовыход, приложение сообщает об этом,
а не имитирует проигрывание.

## Голос и параметры

- Для клонирования нужна чистая запись одного человека, 3-20 секунд, и
  точный текст, произнесённый в ней. Отдельная модель распознавания не нужна.
  Используйте только голос, на применение которого у вас есть разрешение.
- Готовый голос создаётся один раз и сохраняется как голосовой профиль.
  Все фрагменты книги используют один и тот же профиль.
- Шаги синтеза: 16, 32 или 64. По умолчанию 32.
- Скорость модели: 0.7-3.0; скорость готового файла: 0.5-3.0.
- Тембр: -6..+6 полутонов; громкость: -20..+12 дБ.
- После остановки повторный запуск с тем же текстом, голосом и параметрами
  продолжает работу по сохранённым фрагментам.
- Повреждённые и недописанные фрагменты не используются. Сборка результата
  атомарная: ошибка обработки не повреждает уже существующий файл.

Интерфейс работает в главном потоке; загрузка книг, сохранение настроек и
синтез выполняются отдельно. Модель находится в собственном процессе;
остановка и таймаут завершают только этот процесс. Доступ к модели и кэшу
защищён блокировками. Параллельные запросы не перемешиваются.

## Исходники и проверка

В исходном проекте: `install_voicestudio.ps1`, затем `start_voicestudio.cmd`.
Старое приложение `start_aibook.cmd` / `dist\AIBook Portable` остаётся XTTS.

```powershell
.\.voice-venv\Scripts\python.exe .\voice_studio_main.py --doctor
.\.voice-venv\Scripts\python.exe .\voice_studio_main.py `
  --text-file .\examples\sample_ru.fb2 --output .\outputs\book.mp3 --device auto
.\.voice-venv\Scripts\python.exe -m unittest discover -s tests -v
.\build_voicestudio_portable.ps1
```

В готовой папке CLI запускается через `runtime\python\python.exe` и
`app\voice_studio_main.py`. Код приложения расположен в `app`, код движка в
`app\vendor\VoiceStudio\omnivoice`, сборочные исходники и тесты в `source`.
Ошибки: `data\voicestudio\aibook.log` и `voicestudio-worker.log`.
