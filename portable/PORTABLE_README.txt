AIBook XTTS v2 Portable

Supported systems: Windows 10/11 x64.

Run AIBook.cmd. No installation, Python, FFmpeg or internet connection is
required. The folder may be copied or renamed; keep its internal structure and
place it in a writable location.

On a supported NVIDIA GPU the application uses CUDA. On other systems it
falls back to CPU, which is substantially slower.
At least 16 GB of RAM is recommended.

Application data, cached voices, settings and unfinished jobs are stored in
data\aibook. XTTS weights are stored in data\tts. Finished audio is stored in
outputs by default.

XTTS v2 is configured for personal non-commercial use under CPML.
